此仓库仅提供远协安装包、SHA-256 校验文件和下载说明。源码仓库保持私有。

| 系统 | 请选择 |
| --- | --- |
| Windows Intel/AMD | Windows-x64.zip |
| Mac Apple M 系列 | macOS-arm64.dmg 或 .zip |
| Mac Intel | macOS-x64.dmg 或 .zip |
| Linux Intel/AMD | Linux-x64.deb 或 .tar.gz |
| Linux ARM64 | Linux-arm64.deb 或 .tar.gz |

Mac 需要 macOS 13 或更新版本。打开 DMG/ZIP 后将 YuanXie.app 拖入应用程序；当前使用本地 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证，首次打开可能需在系统隐私与安全性设置中确认。摄像头、麦克风、屏幕共享均需系统授权。

Debian/Ubuntu 建议使用系统软件安装器安装对应架构 DEB；其他 Linux 桌面可解压 TAR.GZ 后打开 YuanXie。Wayland 的共享与快捷键由系统桌面门户管理。

Mac/Linux 不提供 Windows 捕获排除保护，共享屏幕时远协窗口可能可见。Windows 应用内安装更新；Mac/Linux 在软件检查更新后跳转此下载页，下载并替换应用或安装新 DEB，原用户配置目录保留。

每个包附带同名 .sha256。附件不包含开发机的数据库、账号、模型密钥或录音。手机和平板可通过浏览器使用共享链接；此处没有 Android/iOS 原生安装包。
